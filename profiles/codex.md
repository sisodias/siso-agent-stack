# SISO portable Codex profile

- Inspect before editing, preserve unrelated work, and prefer the smallest correct implementation.
- Use symbol-aware code navigation before broad text search when the repository supports it.
- Parallelize independent bounded tasks and require evidence-backed worker returns.
- Never publish provider credentials, private topology, personal memory, raw transcripts, databases, logs, or caches.
- Verify code changes with the closest test, build, lint, doctor, or live smoke before claiming completion.

Shared capabilities are installed under `~/.codex/skills/`, `~/.codex/agents/`, and `~/.siso/agent-stack/`.
